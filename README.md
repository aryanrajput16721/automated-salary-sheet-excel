# 💼 Automated Salary Sheet – Excel Payroll Project

This is my **Excel-based salary sheet project**, created to automate payroll calculations and visualize employee compensation breakdowns. It includes dynamic formulas for allowances, deductions, and net salary computation.

## 🎯 Project Objective

To build a professional salary sheet in Excel that calculates employee earnings and deductions automatically, helping HR and finance teams streamline payroll management.

## 📁 Components Included

- 🧾 Basic Salary
- 🏠 HRA (House Rent Allowance)
- 📈 DA (Dearness Allowance)
- 🚕 TA (Travel Allowance)
- 🚗 Conveyance
- ⏱️ Overtime Hours & Rate
- 💰 Gross Salary
- 📉 Deductions: PF, ESI
- ✅ Net Salary

## ⚙️ Process

- Structured employee data with attendance and salary components
- Applied formulas for automated calculations
- Included overtime logic based on hours and rate
- Designed layout for clarity and HR usability
